- preserve the single-template / single-runtime architecture;
- make the unified candidate feel closer to the current calculator without copying localized application code back into the new runtime;

- add a live spend-rate cue, source/methodology disclosure and a shareable stateful preview URL;
- keep `data/model-v2.candidate.json` disconnected from runtime until methodology review is complete;
- keep every preview page `noindex` and leave production routes/files untouched.
